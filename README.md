Project 3: Restaurant Ordering System
Scenario
A restaurant wants a console application to calculate customer bills automatically.
Learning Objectives
• Variables and constants
• Switch statement
• Methods
• Calculations
• Loops
Menu
• Burger - $5
• Pizza - $8
• Fried Chicken - $6
• Soft Drink - $2
Functional Requirements
• Display food menu.
• Allow customer to select items.
• Enter quantity for each item.
• Calculate subtotal.
• Calculate VAT (10%).
• Calculate grand total.
• Print receipt.
Required Methods
• displayMenu()
• calculateItemTotal()
• calculateVAT()
• printReceipt()
